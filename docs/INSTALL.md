# 설치 안내

## Windows

1. 릴리스에서 `HYLauncher_<버전>_x64_ko-KR.msi`를 받는다(영어는 `en-US`, 일본어는 `ja-JP`).
2. 실행하고 안내를 따른다.

**SmartScreen 경고가 뜨는 경우**: 「추가 정보」 → 「실행」. 코드 서명 인증서를 아직 붙이지
않아서 뜨는 경고다. 파일이 릴리스 페이지에서 받은 것인지 확인해 주세요.

**언어를 잘못 받았을 때**: 다시 받을 필요 없다. 런처 설정에서 언어를 바꾸면 된다 —
MSI의 언어는 설치 화면에만 쓰인다.

## Linux

AppImage 하나로 끝난다. 설치랄 것이 없고 어디에 두든 실행된다.

```sh
chmod +x HYLauncher_*.AppImage
./HYLauncher_*.AppImage
```

**로그인과 게임 설치 링크(`hylauncher://`)가 동작하려면** 런처를 한 번 실행해 두어야 한다.
실행할 때마다 `~/.local/share/applications`에 링크 처리기를 등록한다(AppImage를 옮겨도 다음
실행 때 새 위치로 고쳐진다). 여기에 `xdg-utils`가 필요하다 — 대부분의 데스크톱에는 이미 있다.

**FUSE가 없다는 오류가 나면**:

```sh
sudo apt install libfuse2
```

또는 압축을 풀어서 실행한다:

```sh
./HYLauncher_*.AppImage --appimage-extract
./squashfs-root/AppRun
```

## 게임은 어디에 설치되나

| 운영체제 | 기본 경로 |
|---|---|
| Windows | `C:\Users\<사용자>\HYLauncher\<게임>` |
| Linux | `~/HYLauncher/<게임>` |

설정에서 바꿀 수 있다. **바꾼 값은 다음 실행부터 적용되고, 이미 설치된 게임은 옮기지
않는다.**

같은 폴더 안에 런처가 쓰는 자리가 몇 개 더 있다:

- `.cache/` — 내려받는 중인 파일. 중간에 끊겨도 여기서 이어받는다.
- `.trash/` — 지운 것들이 7일간 머무는 곳. 실수로 지웠다면 여기서 꺼낼 수 있다.

## 게임 버전 고르기

게임 화면의 **버전**에서 고른다.

| 고르는 것 | 받는 버전 |
|---|---|
| 최신 릴리스 (기본) | 가장 새 정식 버전 |
| 최신 — 테스트 버전 포함 | 공개·비공개 테스트까지 포함해 가장 새 버전 |
| 특정 버전에 고정 | 그 버전. 새 버전이 나와도 업데이트하지 않는다 — 모드를 쓸 때 |

고르기만 해서는 아무것도 받지 않는다. 고른 뒤 나타나는 **업데이트**·**바꾸기** 버튼을 눌러야
받는다. 이전 버전으로 내려가면 새 버전에서 만든 세이브를 읽지 못할 수 있다.

**비공개 테스트 코드**를 받았다면 라이브러리 화면 위쪽이나 게임 화면에 넣는다. 그 게임의
비공개 테스트 버전이 버전 목록에 나타나고, 이후의 테스트 버전도 계속 보인다.

## 제거

Windows는 설정 → 앱에서, Linux는 AppImage 파일을 지우면 된다.

**게임과 세이브는 함께 지워지지 않는다.** `HYLauncher` 폴더를 직접 지워야 한다. 클라우드
세이브는 계정에 남으므로 [hyproj.com](https://hyproj.com)의 라이브러리에서 지운다.
