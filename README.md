# HY Launcher

> **HY Project** presents · Making World, Making Memories

HY Project의 게임을 설치하고, 최신으로 유지하고, 세이브를 어느 기기에서든 이어 가는 런처.

이 저장소는 **설치본과 안내문**이 사는 곳이다. 소스 코드는 비공개 저장소에 있다.

---

## 받기

[릴리스 페이지](../../releases/latest)에서 운영체제에 맞는 파일을 받는다.
[hyproj.com](https://hyproj.com)에서 받아도 같다.

| 운영체제 | 파일 |
|---|---|
| Windows | `HYLauncher_<버전>_x64_ko-KR.msi` (한국어) · `en-US` (English) · `ja-JP` (日本語) |
| Linux | `HYLauncher_<버전>_amd64.AppImage` |

**Windows 파일이 언어별로 나뉜 이유**: MSI는 언어가 설치 패키지 자체에 구워져서, 설치
마법사 안에서 언어를 고를 수 없다. 그래서 언어마다 파일이 하나씩이다. **어느 것을 받든
런처 자체의 언어는 설정에서 바꿀 수 있다** — 달라지는 것은 설치 화면뿐이다.

**Linux가 DEB가 아닌 이유**: 자가 업데이트가 AppImage에서만 동작한다. DEB로 주면 새 버전이
나와도 런처가 스스로 갱신하지 못한다.

AppImage는 받은 뒤 실행 권한을 준다:

```sh
chmod +x HYLauncher_*.AppImage
./HYLauncher_*.AppImage
```

---

## 하는 일

- **설치와 업데이트** — 보유한 게임을 한곳에서 받고, 새 판이 나오면 알린다.
- **클라우드 세이브** — 게임을 켤 때 내려받고 끄면 올린다. 게임마다 켜고 끌 수 있다.
- **HY 계정 연결** — [hyproj.com](https://hyproj.com)의 계정으로 로그인한다. 로그인은 여러분의
  기본 브라우저에서 이루어진다 — 런처는 비밀번호를 보지 않는다.

---

## 처음 쓸 때

1. 런처를 설치하고 실행한다.
2. **HY 계정으로 로그인**을 누르면 브라우저가 열린다. 거기서 허용하면 런처로 돌아온다.
3. 라이브러리에서 게임을 고르고 **설치**를 누른다.

게임은 기본적으로 `사용자 폴더\HYLauncher\<게임>`에 설치된다(Linux는 `~/HYLauncher/<게임>`).
설정에서 바꿀 수 있다.

## 알아 두면 좋은 것

**웹사이트에서 받은 설치본과 세이브를 공유하지 않는다.** 런처는 게임을 자기 폴더에 풀고
세이브도 그 옆에 두기 때문이다. 예전 설치본의 세이브를 이어 가려면 그 `save/` 폴더의 파일을
런처가 설치한 게임의 `save/`로 옮긴다.

**로컬 세이브를 지워도 클라우드 사본은 남는다.** 클라우드 세이브가 켜진 채로 게임을 다시
켜면 그것을 도로 내려받는다. 완전히 처음부터 시작하려면 클라우드 세이브도 함께 지운다.

**세이브가 충돌하면 한쪽을 골라야 한다.** 두 기기에서 따로 진행하면 생길 수 있다. 런처는
두 저장본을 합치지 않는다 — 합치면 어느 쪽도 아닌 상태가 되고, 그건 하나를 잃는 것보다
나쁘다. 고르지 않은 쪽은 7일간 보관한다.

더 자세한 것은 [설치 안내](docs/INSTALL.md)와 [문제 해결](docs/TROUBLESHOOTING.md)에 있다.
